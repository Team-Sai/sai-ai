# SAI AI

사이원장 계약 법령 검색 및 S-AI 계약 조항 생성 서비스.

## Environment

- Python 3.11
- FastAPI
- Qdrant
- BGE-M3
- BGE Reranker
- OpenAI

## Setup

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
copy .env.example .env
```
